HONTI 3-Gate — самостоятельный integration runtime для SAP и других корпоративных источников. Он отвечает за извлечение, инкрементальность, восстановление после ошибок и доставку данных — независимо от бизнес-логики DWH.

Граница продукта

3-Gate знает, как получить данные и гарантированно доставить их дальше.

Оркестрация процессов остаётся в Flow, моделирование и трансформации — в Data Platform. Благодаря этому 3-Gate можно поставить отдельно или использовать как штатный integration layer всей платформы HONTI.

01

Incremental by design

Watermark и состояние выполнения хранятся отдельно от бизнес-логики. Повторный запуск продолжает загрузку, а не начинает её заново.

02

Schema-aware

Метаданные источника читаются runtime-слоем. Политики strict, compatible и evolve позволяют контролировать изменение схемы.

03

Recoverable

Staging, атомарная публикация результата, retry и checkpoint защищают target от частично завершённых загрузок.

HONTI Flow + 3-Gate

Отдельный продукт. Внутри Flow — штатный исполнитель интеграции.

Зависимость односторонняя: Flow вызывает 3-Gate, но 3-Gate ничего не знает о Flow. Поэтому integration runtime остаётся универсальным.

Prototype
Analyzer ↓ metadata / dependencies Flow ↓ extraction job 3-Gate ↓ canonical/raw dataset S3 / ClickHouse / PostgreSQL ↓ Data Platform / DWH
Flow решает «когда»

Расписание, зависимости, ветвление, последовательность pipeline.

3-Gate решает «как»

Подключение, чтение, schema mapping, delta, retry, checkpoint и доставка.

Первый прототип

Начинаем с минимального промышленного ядра.

Первая версия: декларативные jobs, состояние запусков и watermark в SQLite, атомарный файловый sink и адаптерная модель для SAP RFC. Следующие шаги — реальный SAP NWRFC connector, Parquet/S3 и ClickHouse sink, затем API для Flow.

Pilot
