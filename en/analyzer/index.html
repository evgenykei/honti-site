How it works

Collect. Connect. Analyze.

Collect

The demo uses fictional data and supports your own JSON files. Connecting a SAP source is a separate step.

Connect

Normalize objects and dependencies into a graph: objects become nodes and technical dependencies become edges.

Analyze

Explore paths, filter the landscape and use the graph to analyze changes, architecture and migration.

The planned solution automates metadata collection using the same approach: capture the landscape state, then analyze the stored model rather than rebuilding it for every user request.
