HONTI 3-Gate is a standalone integration runtime for SAP and other enterprise sources. It handles extraction, incremental loading, error recovery and data delivery, independently of DWH business logic.

Product scope

3-Gate handles data extraction and reliable delivery.

Process orchestration stays in Flow; modeling and transformations stay in the Data Platform. Deploy 3-Gate independently or use it as the integration layer of the HONTI platform.

01

Incremental by design

Watermarks and execution state are stored separately from business logic. A restart resumes the load instead of starting over.

02

Schema-aware

The runtime reads source metadata. Strict, compatible and evolve policies control schema changes.

03

Recoverable

Staging, atomic publication, retries and checkpoints protect the target from incomplete loads.

HONTI Flow + 3-Gate

A standalone product. The integration runtime within Flow.

The dependency runs one way: Flow calls 3-Gate, while 3-Gate is independent of Flow. The runtime can therefore be used in other environments.

HONTI 3-Gate
Analyzer ↓ metadata / dependencies Flow ↓ extraction job 3-Gate ↓ canonical/raw dataset S3 / ClickHouse / PostgreSQL ↓ Data Platform / DWH
Flow decides when

Scheduling, dependencies, branching and pipeline sequencing.

3-Gate handles how

Connections, extraction, schema mapping, deltas, retries, checkpoints and delivery.
