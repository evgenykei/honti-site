# Публикация HONTI Analyzer

Основной код приложения развивается в [evgenykei/bw-relation-flow](https://github.com/evgenykei/bw-relation-flow). Этот репозиторий публикует проверенный снимок в `analyzer/demo/` и содержит страницы корпоративного сайта.

Вносите изменения в основной репозиторий через PR, запустите `npm test`, затем из чистой рабочей копии выбранного коммита выполните `npm run export:site -- --target ../honti-site`. Скрипт экспортирует только файлы приложения и записывает `analyzer/demo/RELEASE.json` с commit SHA источника и контрольными суммами. Проверьте diff и откройте PR здесь. Главная страница и продуктовая посадочная страница не входят в экспорт.

Не редактируйте runtime приложения независимо в honti-site. Если потребуется срочное исправление, оно сначала фиксируется в основном репозитории и затем публикуется тем же путём. Исторические тесты сайта можно использовать для дополнительной проверки, но актуальные тесты модели и сценариев находятся в основном репозитории.

Начальная запись RELEASE.json соответствует переносу в PR № 2 основного репозитория. Файлы runtime совпадают с уже опубликованным состоянием; этот PR фиксирует происхождение, а не добавляет новую функциональность. Ссылка на commit работает до и после слияния PR.
